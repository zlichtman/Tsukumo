# Legacy

The code of the two apps Tsukumo replaced, kept for reference as they stood on September 30, 2026: the old Tsukumo coding harness for Mac (Tsukumo 77) in `macos/`, and the KemoSabe iPhone app with its Apple Watch app and widgets (build 69) in `ios/`, which also holds the sources and resources the old Mac app compiles. Nothing in the current apps builds from here. To build either, run `xcodegen generate` in `legacy/macos` or `legacy/ios` and open the project it makes.
